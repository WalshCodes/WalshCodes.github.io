# Academic & Developer Journey

I am a Computer Science undergraduate student at Thompson Rivers University (TRU) in Kamloops, British Columbia. My academic journey combines deep theoretical principles—such as algorithmic efficiency, abstract data structures, and software architecture—with pragmatic, hands-on engineering.

I enjoy engineering tools that bridge the gap between low-level performance and clean user interactions. Whether that means integrating Python scripts into a C# desktop utility, designing decoupled software architectures in Java, or writing snappy, responsive frontend web applications without bloated dependencies, I focus on clean code, modular design, and robust architecture.

Version control and open-source practices are central to my daily workflow. You can find my repositories, academic coursework, and personal experiments under my GitHub handle, @WalshCodes.
